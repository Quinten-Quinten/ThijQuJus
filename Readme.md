# ThijQuJus Space Invaders

## Beschrijving
Een recreatie van het oude spel space invaders gemaakt met pygame

## Reflectie
### Justin
Tijdens deze opdracht heb ik veel geleerd over hoe je een spel maakt in Python met Pygame. In het begin vond ik het vooral lastig om alles tegelijk te laten werken, zoals de beweging van de speler, het schieten van kogels en het bewegen van de aliens. later begon ik beter te begrijpen hoe de game loop werkt en hoe alles daarin steeds opnieuw wordt geüpdatet. Wat ik het meest heb geleerd is werken met functies en lijsten. Door functies te gebruiken voor dingen zoals het tekenen van het schip, kogels en aliens werd mijn code overzichtelijker. Ook het gebruik van lijsten voor kogels en aliens vond ik eerst lastig, maar later snapte ik hoe je daarmee meerdere objecten tegelijk kunt beheren. Het debuggen van fouten was soms irritant, vooral met dingen zoals indentation errors of variabelen die niet goed waren gedefinieerd. Maar daardoor ben ik wel beter gaan begrijpen hoe Python precies naar code kijkt. Kleine foutjes kunnen al snel zorgen dat iets niet werkt, dus daar ben ik zorgvuldiger in geworden. Ook het maken van extra functies zoals waves en score gaf de game meer interessanten aspecten. Hierdoor voelde het spel veel beter en niet zo saai want je kan echt laten zien hoe ver je bent gekomen in het spel het is ook leuk dat het spel na elke wave steeds moeilijker wordt. De samenwerking ging over het algemeen goed. We hebben taken verdeeld en elkaar geholpen wanneer iemand vastliep. Soms werkten we samen aan dezelfde bugs om ze sneller op te lossen. Wat beter had gekund is dat we eerder een duidelijke structuur hadden bedacht voordat we begonnen met coderen. Ik ben vooral trots dat de game nu echt volledig werkt met startscherm, score, waves en game over scherm. Als ik het opnieuw zou doen zou ik eerder plannen en minder gewoon beginnen en kijken wat er gebeurt.

### Quinten
Voor dit project hebben Justin, Thijmen en ik een alien shooter-game gemaakt met Python, Pygame en GitHub. Tijdens het maken van het spel heb ik veel geleerd over programmeren, samenwerken en het maken van keuzes binnen een project. Ik had eerst weinig ervaring met het maken van games. Tijdens dit project leerde ik hoe beweging, hitboxes en een game loop werken in Pygame. Vooral het programmeren van aliens en kogels was soms lastig. Door fouten stap voor stap te testen en te overleggen met Thijmen en Justin, begreep ik beter hoe game-logica werkt. Ook leerde ik hoe belangrijk overzichtelijke code is. Door functies en duidelijke variabelen te gebruiken, werd de code makkelijker te begrijpen en konden we beter samenwerken. Daarnaast heb ik geleerd om zelfstandig maar ook gezamenlijk oplossingen te zoeken wanneer iets niet werkte. De samenwerking met Justin en Thijmen verliep goed. We verdeelden de taken en hielpen elkaar wanneer iemand vastliep. Hierdoor verliep alles goed en vlekkeloos. Ik heb geleerd dat communicatie erg belangrijk is bij programmeren. Je moet duidelijk uitleggen wat je doet, zodat anderen jouw code begrijpen. Hierdoor werd onze samenwerking sterker. We kozen voor een alien shooter omdat dit goed past bij de mogelijkheden van Pygame en het ons herinnerde aan onze jeugd. Ook besloten we eerst de basis van het spel werkend te maken voordat we extra functies toevoegden. Hierdoor bleef het project overzichtelijk. Ik kijk positief terug op dit project. Ik heb veel geleerd over programmeren in Python en samenwerken binnen een team, ook weet ik nu hoe GitHub werkt omdat Justin mij dit heeft uitgelegd. Bij het vorige PO wist ik dit nog niet, dus ik ben blij dat het mij nu wel is gelukt. Door samen te werken met Justin en Thijmen hebben we een spel gemaakt waar ik trots op ben.
